Rédige ou mets à jour un document de passation pour qu'un nouvel agent avec un contexte frais puisse continuer ce travail.

Étapes :
1. Vérifier si HANDOFF.md existe déjà dans le projet
2. S'il existe, le lire d'abord pour comprendre le contexte précédent avant de le mettre à jour
3. Créer ou mettre à jour le document avec :
   - **Objectif** : Ce qu'on essaie d'accomplir
   - **Progression actuelle** : Ce qui a été fait jusqu'ici
   - **Ce qui a fonctionné** : Approches qui ont réussi
   - **Ce qui n'a pas fonctionné** : Approches qui ont échoué (pour ne pas les répéter)
   - **Prochaines étapes** : Actions claires pour continuer

Sauvegarder sous HANDOFF.md à la racine du projet et indiquer le chemin à l'utilisateur pour qu'il puisse démarrer une nouvelle conversation avec juste ce fichier.
